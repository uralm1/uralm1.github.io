Как поднять точку доступа с командной строки с помощью NetworkManager и nmcli. 
<!--more-->

Убедиться, что установлен `wpa-supplicant` и wifi адаптер поддерживает режим точки доступа:
```
iw list
# смотреть в Supported interface modes, AP-режим точки доступа
```

### Настройка connection (профиля соединения):
```
sudo nmcli connection add type wifi ifname wlan0 con-name myap autoconnect yes ssid TESTAP
# ssid и con-name установить по желанию

sudo nmcli conn modify myap \
  802-11-wireless.mode ap \
  802-11-wireless.band bg \ # "bg"-2.4 Ггц, "a"-5 Ггц
  802-11-wireless.channel 6 \ # можно не  указывать, будет channel 0 - авто
  ipv4.method shared \ # shared или manual см.далее
  ipv4.addresses 192.168.50.1/24 \
  wifi-sec.key-mgmt wpa-psk \
  wifi-sec.psk "пароль" # пароль >=8 и <63 символов, иначе будет непонятная "invalid property value"
```

### Поднятие и просмотр connection:
```
sudo nmcli conn up myap
nmcli conn show
nmcli device status

sudo nmtui # также можно редактировать через текстовый интерфейс

# переименовать connection
sudo nmcli conn modify oldname connection.id newname
```

### Режимы 802-11-wireless.mode

| 802-11-wireless.mode | описание |
| --- | --- |
| infrastructure | клиентский режим, подключение к другой точке доступа |
| ap | точка доступа |
| adhoc | устаревший вариант одноранговой сети без точек доступа |
| mesh |  |
| monitor |  |

### Варианты ipv4.method

| ipv4.method | описание |
| --- | --- |
| shared | поднимается NAT+DHCP |
| manual | ip адрес надо устанавливать на клиенте самостоятельно из диапазона ipv4.addresses |
| auto | внешний dhcp ? |
| disabled | выкл.ipv4 на интерфейсе |
| link-local | 169.254.0.0/16 |

```
# можно задать
ipv4.gateway 192.168.50.1
ipv4.dns 8.8.8.8
```
